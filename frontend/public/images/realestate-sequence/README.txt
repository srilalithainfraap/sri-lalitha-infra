SRI LALITHA INFRA — Scroll Sequence Frames
===========================================

Place JPG frames here named exactly:
  1.jpg, 2.jpg, 3.jpg, ... 240.jpg

The sequence plays as the user scrolls through the 500vh hero section.
Frames should depict a luxury plotted development — entrance gate, roads,
greenery, aerial views — at golden hour.

Recommended: 240 frames at 1920x1080, quality 75–85%, roughly 80–120KB each.

If this folder is empty or frame 1.jpg is missing, the website falls back
to a Ken Burns (slow zoom/pan) effect on /assets/hero-bg.jpg automatically.
